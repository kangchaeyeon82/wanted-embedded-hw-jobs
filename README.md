# 원티드 임베디드·하드웨어 채용 요건 분석

[원티드](https://www.wanted.co.kr/wdlist/518?country=all&job_sort=job.popularity_order&years=-1&selected=658&selected=672)의 **임베디드 개발자(658)**와 **하드웨어 엔지니어(672)** 공고를 모두 모아 자격 요건과 우대 사항을 키워드별로 정리한 프로젝트입니다. 정리한 결과는 대시보드와 학습 로드맵으로 만들었습니다.

- 📊 대시보드: https://claude.ai/artifact/1v9jikZnt3nHQfE6HggcXE
- 📘 학습 로드맵 보고서: https://claude.ai/code/artifact/e66594ab-3882-4e73-99bd-2834e39808a6

> 수집 시점: 2026-10-12 · 공고 242건 · 회사 149곳

## 주요 결과

| 지표 | 전체 | 임베디드 | 하드웨어 |
|---|---|---|---|
| 공고 수 | 242 | 139 | 103 |
| 회사 수 | 149 | 98 | 72 |
| 신입(0년) 지원 가능 | 31건 (13%) | 14건 (10%) | 17건 (17%) |
| 최소 경력 중앙값 | 3년 | 3년 | 3년 |
| 수도권 근무 비율 | 88% | 90% | 86% |
| C/C++을 필수로 요구 | 48% | 66% | 24% |

- **임베디드**: 필수 요건으로 C/C++(66%) 다음에 Linux(33%)와 Python(31%)을 많이 요구합니다.
- **하드웨어**: 회로 설계(22%)가 가장 많고, PCB, 계측장비, MCU가 각각 17%입니다.
- **학력·전공**: 전자/전기공학(37%)과 컴퓨터공학(35%)이 많습니다. 공통 역량으로는 커뮤니케이션/협업(42%)을 가장 많이 언급합니다.
- **경력**: 경력 2년 이하 공고가 73건(30%)입니다. 신입이 지원할 수 있는 공고도 꽤 있습니다.

## 파이프라인

```
fetch_list.py  →  fetch_detail.py  →  analyze.py  →  prep.py  →  out/*.json
 (공고 목록)        (공고 상세)         (키워드 매칭)    (집계)        (대시보드 데이터)
```

| 스크립트 | 하는 일 |
|---|---|
| `fetch_list.py` | 원티드 목록 API(`/api/chaos/navigation/v1/results`)에서 공고를 100건씩 받아 `data/list.json`에 저장합니다. |
| `fetch_detail.py` | 상세 API(`/api/v4/jobs/{id}`)에서 공고마다 상세 정보를 받아 `data/d/{id}.json`에 저장합니다. 6개 스레드로 받고, 실패하면 다시 시도합니다. |
| `analyze.py` | 자격 요건과 우대 사항 본문을 정규식 사전으로 매칭합니다. 사전은 9개 그룹, 약 100개 스킬이며 학력과 공통 역량 사전도 따로 있습니다. 결과는 `jobs.json`에 저장합니다. |
| `prep.py` | 직군(임베디드/하드웨어), 경력 구간, 근무지별로 집계해 `out/*.json`을 만듭니다. |
| `stats2.py`, `tok.py` | 보조 통계를 내고, 사전에 빠진 키워드를 찾는 데 썼습니다. |

### 스킬 사전의 9개 그룹

언어 · OS·플랫폼 · 프로세서·칩 · 통신·인터페이스 · HW 설계·검증 · 개발 도구·방법론 · AI·비전 · 로보틱스·제어 · 차량·안전 표준

C와 C++은 집계할 때 `C/C++` 하나로 합쳤습니다.

## 실행 방법

Python 3.9 이상이 필요하고, 표준 라이브러리만 사용합니다.

```bash
python fetch_list.py
python fetch_detail.py
python analyze.py
python prep.py
```

Windows 콘솔에서 한글이 깨지면 `PYTHONIOENCODING=utf-8`을 설정하세요.

## 결과 파일 (`out/`)

| 파일 | 내용 |
|---|---|
| `jobs.json` | 공고별 회사, 포지션, 직군, 최소 경력, 근무지, 필수·우대 키워드 |
| `skills.json` | 직군별 스킬 빈도(필수 / 우대만)와 비율 |
| `years.json` | 경력 구간 분포 |
| `locations.json` | 근무지 분포 |
| `education.json` | 학력·전공 요건 빈도 |
| `soft_skills.json` | 공통 역량 빈도 |
| `summary.json` | 직군별 핵심 지표 |
| `index.html` | 대시보드 페이지 소스 |

`out/index.html`은 Claude 대시보드 런타임(`window.dash`)에서 실행되도록 만든 페이지입니다. 브라우저에서 파일을 바로 열면 데이터가 표시되지 않으니 위의 대시보드 링크로 보세요.

## 참고

- 원본 공고 데이터(`data/`)는 원티드 콘텐츠이므로 저장소에 넣지 않았습니다. 스크립트를 실행하면 다시 받을 수 있습니다.
- 키워드는 정규식으로 매칭했기 때문에 문맥은 반영하지 못합니다. 그래서 빈도에 약간의 오차가 있을 수 있습니다.
- 공고는 계속 바뀌므로 이 결과는 수집 시점 기준입니다.
